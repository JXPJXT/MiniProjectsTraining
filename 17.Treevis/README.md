## 🎯 What It Does

Explore the **House Targaryen royal lineage** through two interfaces:

1. **🌐 Interactive HTML Visualization** — A dark, fire-themed web page with gold-accented node cards, search functionality, member info panels, and tree statistics. Generated by Python and opened directly in the browser.
2. **🖥️ ANSI Terminal Tree** — A beautifully formatted tree printed to the console with color-coded names, emoji icons (👑, ⚔️, 🐉), and lineage statistics.

## 🚀 Quick Start

### Prerequisites
- Python 3.x
- A modern web browser

### Run

```bash
python got_visualizer.py
```

This will:
1. **Print** the Targaryen family tree to the terminal with ANSI colors
2. **Display** lineage statistics
3. **Generate** an HTML file and **open it** in your default browser

### Or View the Pre-Generated HTML

Simply open `targaryen_lineage.html` directly in your browser:

```bash
# Windows
start targaryen_lineage.html

# macOS
open targaryen_lineage.html

# Linux
xdg-open targaryen_lineage.html
```

## 🧠 Data Structure Concepts

This project demonstrates several tree operations:

| Operation | Method | Description |
|---|---|---|
| **Add Node** | `tree.add(parent, child)` | Insert a child under a parent |
| **Parent Lookup** | `tree.parent_of(name)` | Find direct parent |
| **Children** | `tree.children_of(name)` | List direct children |
| **Ancestors** | `tree.ancestors_of(name)` | Trace path up to root |
| **Descendants** | `tree.descendants_of(name)` | DFS to find all descendants |
| **Path to Root** | `tree.path_to_root(name)` | Full path from root to node |
| **Lineage Check** | `tree.is_descendant(a, b)` | Check if A descends from B |
| **Depth** | `tree.depth_of(name)` | Distance from root |
| **Tree Height** | `tree.height()` | Longest root-to-leaf path |
| **Size** | `tree.size()` | Total node count |
| **Serialization** | `tree.to_json()` | Export tree as JSON |
